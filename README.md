<h1>React Project</h1>
<p>In this Project React, Vite and Redux are used to make an E-Commerce Application which incorporates
    basic functionalities of browsing products, adding product to cart, viewing more detailed
    description of product, category vise filtering, product search,etc. </p>

<h1>Objective of this project are:</h1>
<ol>
    <li>To develop home page containg all product and category list of product </li>
    <li>To fetch data from dummy api using custom hook</li>
    <li>To use react for bulding the application</li>
    <li>To build Browse Product page that includes functionalities such as: Product search, filtering by category </li>
    <li>To develop product details page where detailed description of the product can seen</li>
    <li>To use Redux to manage state of the items in the cart</li>
    <li>To use Redux to manage state of search query</li>
    <li>To optimize performance using lazy loading</li>
    <li>To make application responsive</li>
</ol>

<h1>Tech stack used:</h1>
<ul>
    <li>React</li>
    <li>Redux</li>
    <li>Tailwind</li>
    <li>React router DOM</li>
    <li>Axios</li>
    <li>React Icons</li>
</ul>

<h1>Features:</h1>
<ol>
    <li>Header
        <ul>
            <li>Navigation bar with home and cart links</li>
        </ul>
    </li>
    <li>HomePage
        <ul>
            <li>shows welcome message</li>
            <li>search product</li>
            <li>shows products</li>
            <li>filter products by category</li>
        </ul>
    </li>
    <li>search
        <ul>
            <li>search by brand</li>
            <li>search by title</li>
        </ul>
    </li>
    <li>Product list
        <ul>
            <li>shows all products grid layout</li>
        </ul>
    </li>
    <li>Product Item
        <ul>
            <li>shows product image</li>
            <li>shows ratings and review count</li>
            <li>shows brand</li>
            <li>shows pruduct title</li>
            <li>shows price</li>
            <li>Add to cart button</li>
        </ul>
    </li>
    <li>Product Details
        <ul>
            <li>shows product image</li>
            <li>shows brand</li>
            <li>shows category</li>
            <li>shows pruduct title</li>
            <li>shows ratings and review count</li>
            <li>shows description</li>
            <li>shows stock</li>
            <li>shows price</li>
            <li>Add to cart button</li>
        </ul>
    </li>
    <li>Cart
        <ul>
            <li>Products can be added to cart</li>
            <li>Quantity of product item can be increased</li>
            <li>Quantity of product item can be decreased</li>
            <li>Product can be removed from cart</li>
            <li>Clear cart with single click</li>
        </ul>
    </li>
    <li>Checkout
        <ul>
            <li>Shipping details</li>
            <li>Order summry</li>
            <li>Grand total of price</li>

        </ul>

</ol>
